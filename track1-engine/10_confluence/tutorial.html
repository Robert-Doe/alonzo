00Prerequisites

P6.3 confluence (the diamond) P6.4 →, →* P5.1 induction

From the course: de Bruijn keys (Module 6) merge α-equivalent nodes, one-step reducts (Module 8) are the edges, and Module 9 showed that strategies which finish agree, which is what this module explains.

01The Big Analogy

A term's reduction graph is a city map where every street leads downhill toward one valley.

Each intersection is a term. Each one-way street is a single β-step. At most intersections you can take several streets, and different drivers take different routes. Church–Rosser is the city planner's guarantee: whenever two drivers split up, there is always somewhere further down where they can meet again.

So if there is a valley floor (a normal form), there's only one, and no turn you take can ever cut you off from it. Some streets loop back uphill forever (Ω), so you can fail to arrive by driving in circles, but you can never be stranded.

Residuals are the other half: when one driver clears a roadblock (fires redex S), what happens to another roadblock R? It might be copied (now there are two), erased, or kept, possibly changed.

02What Happens, Step by Step

  1. reductionGraph(t) starts a breadth-first search from t.
  2. For each node, every β-redex gives one outgoing edge (Module 8's stepAt), labelled by the redex's path.
  3. Each new term gets an α-invariant key (its de Bruijn printout). Terms with a known key reuse the existing node, which is how loops become self-edges.
  4. Limits on node count and term size stop infinite graphs, and set truncated.
  5. confluenceReport computes reachability, then checks every fork: do the two branches reach a common node?
  6. residuals(t, S, R) marks R's λ, fires S, and finds the marked copies.
  7. develop(t) contracts all of t's original redexes inside-out: Takahashi's M*.

Module 6 pays off here. α-equivalence is a string compare, so Ω's step back to itself hits known and becomes a self-loop instead of an endless chain.

Residuals by marking

const { ctx, focus } = decompose(t, [...tracked, "fn"]);   // R's λ
const renamed = renameBinder(focus, MARK);                  // α-convert it to "__res": meaning unchanged
const reduct = stepAt(plug(ctx, renamed.term), fired, "beta").reduct;
const res = findRedexes(reduct).filter(r => /* its λ is still named __res… */);

Substitution copies or drops whole sub-terms, so the marked λ travels with every copy of R. A redex created by the step was never marked, so it isn't a residual.

Complete development

export function develop(t: Term): Term {
  switch (t.kind) {
    case "var": return t;
    case "lam": return Lam(t.param, develop(t.body));
    case "app":
      if (t.fn.kind === "lam") return subst(develop(t.fn.body), t.fn.param, develop(t.arg));
      return App(develop(t.fn), develop(t.arg));
  }
}
How the real proof goes

Directly proving "forks rejoin" fails, because one step can copy a redex, so rejoining may take many steps. Tait and Martin-Löf's fix was to define parallel reduction ⇒ (contract any set of existing redexes at once), which does have the one-step diamond property, and whose repetition equals →*. Takahashi (1995) shortened it further: every one-step reduct of M reaches the single term M*, "the triangle". The tests check that triangle on random terms.

BULLET POINTS
  • A reduction graph shows every path. α-merging turns loops into self-edges.
  • Church–Rosser: forks always rejoin. So normal forms are unique, and can never become unreachable.
  • Residuals: firing S can copy, erase or keep another redex R. It can also create brand-new redexes.
  • M* contracts all of M's own redexes at once. It's the heart of the short proof.

05Limits: What You Cannot Do Yet

Can't do yet

  • Prove Church–Rosser for all terms. We check finite graphs; the proof is by induction (see the callout above).
  • Explore infinite graphs fully, so limits truncate them.
  • Use η in the graph. Confluence of βη is true too (Module 11 adds η-steps).

Can do now

  • Draw every reduction path of a small term.
  • Check fork-rejoin, unique normal forms and "no node cut off" on it.
  • Track residuals through a step, and tell created redexes apart.
  • Compute complete developments and test the triangle property.

Getting a blank or broken result?
  • "TRUNCATED": the graph hit a limit (maxNodes or maxSize). Raise them for small growing terms, or accept partial conclusions for infinite graphs.
  • "cannot mark the redex": the tracked path must be a β-redex (its fn must be a λ). Take paths from findRedexes.
  • "Why isn't M* a normal form?": it contracts only M's original redexes. Created ones, like (λy. y) a, survive.

07Brain Exercise

Think before you reveal

In (λx. y) Ω you can keep firing the Ω redex forever and never reach y. That sounds like a reduction that "lost" the normal form.

Try to construct a term M that has a normal form, and a reduct M' of M (reachable by some steps) from which that normal form is no longer reachable at all. If you can't, explain why no such M exists, and why the Ω loop doesn't count.

Hunt for one in the Lab
Reveal the answer

No such M exists. Suppose M →* N (N normal) and M →* M'. By Church–Rosser there's a P with N →* P and M' →* P. But N is normal, so it has no steps, which means P = N. Therefore M' →* N: the normal form is still reachable from M'. (The Lab reports this for every term you try: "every node can still reach the normal form".)

The Ω loop doesn't count because firing Ω returns to the same node, from which y is still one step away. You can fail to take the exit, but it never disappears. That's precisely the difference between "some strategy may not terminate" (Module 9) and "the answer is lost" (impossible). It's why normal order, which always takes the outermost exit, is guaranteed to find it.

08There Are No Dumb Questions

Who were Church and Rosser?

Alonzo Church and his student J. Barkley Rosser proved the theorem in 1936, the same year Church used the λ-calculus to show the Entscheidungsproblem unsolvable. Without confluence, "the value of a term" wouldn't even be well-defined.

If forks always rejoin, why can the number of steps differ so much between paths?

Confluence says the paths meet, not that they're equally long. Duplication (Module 8) and discarding (Module 9) make some paths much longer, or infinite, as in the Ω loop.

Is every rewriting system confluent?

No. Add the rules a → b and a → c with b and c normal, and a has two normal forms. The λ-calculus is special: its single rule, applied anywhere, never creates an irreconcilable choice.

What's a "created" redex, exactly?

One that didn't exist anywhere before the step. In (λf. f P) (λw. w), firing the outer redex puts λw. w in function position: (λw. w) P is brand new. Created redexes are why M* isn't always normal.
