The Eight Ideas Everything Else Assumes

Every module links back to specific sections of these pages with small #tag links. It never re-teaches them inline. Read one when a module sends you here, not all of them up front.

Why these eight?

An OS course assumes registers, endianness, memory addressing and instructions. The λ-calculus has its own primitives. They are not hardware ideas. They are ideas about functions, names, trees and rules. If you know these eight things, every module in the course is readable.

P1
Functions as Mappings
A function is a rule from inputs to outputs. It is also a value you can pass around. Currying.
P2
Variables, Binding & Scope
Which x is this x? Binders, scopes and shadowing.
P3
Trees & Recursion
Programs are trees, and trees are processed by functions that call themselves on the children.
P4
Grammars & BNF
Writing down which strings are legal, plus precedence and associativity.
P5
Structural Induction
Proving "for every term…" by handling each tree shape once.
P6
Rewriting Systems
Computation as "find a pattern, replace it". Normal forms, termination, confluence.
P7
Inference-Rule Notation
The fraction-bar rules that every type system and semantics paper uses.
P8
Reading the Course's TypeScript
Tagged unions, switch on kind, and how to run a .ts file with Node.

How the course is wired

Each module folder is a standalone, runnable snapshot. It has src/, test.ts, demo.ts, DECISIONS.md and tutorial.html. The webapp's Labs import the same src/ files, so what you poke at in the browser is exactly the code you read.
