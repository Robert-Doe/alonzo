Currying and the Arrow

Application groups left, function types group right. They aren't two separate conventions: they're one convention seen from the value side and from the type side.

Follow the types of f a b

Let f : A → B → C. Under right-associativity that's A → (B → C): f takes an A and returns a function B → C.

f          : A → (B → C)
f a        : B → C          ← peel one arrow from the LEFT of the type…
(f a) b    : C              ← …by applying on the LEFT of the term

Each application removes the leftmost argument type. For that to line up with no parentheses, application must group left ((f a) b) while the arrow groups right (A → (B → C)). Flip either one and every curried call needs parentheses.

Schönfinkel's trick, in types

A two-argument function (A × B) → C and its curried form A → (B → C) carry the same information. That's the isomorphism behind currying, published by Schönfinkel in 1924 (rebuilt in Track H1) and later named after Haskell Curry. The λ-calculus takes the curried side as primitive: every λ takes one argument, and λx y. M is shorthand.

Module 13's pairs close the loop. You can write the uncurried version as λp. M[x := fst p, y := snd p], a function of a single pair. Converting between the two is curry = λf a b. f (pair a b) and uncurry = λf p. f (fst p) (snd p).

Where you'll meet the arrow

  • Module 24 (STLC): types τ ::= base | τ → τ, with → right-associative, and the typing rule for application peeling the left arrow.
  • Module 26 (Hindley–Milner): inferred types like K : α → β → α, printed with minimal parentheses by the same "only where the convention would regroup" logic as Module 1's printer.
  • Module 27 (Curry–Howard): A → B → C read as the proposition "A implies (B implies C)". Implication is right-associative in logic for exactly the same reason.
How this connects

Associativity isn't cosmetics. It's the syntactic shadow of "functions take one argument". Pick the directions consistently (application left, arrow right, λ right) and curried code needs no parentheses.
