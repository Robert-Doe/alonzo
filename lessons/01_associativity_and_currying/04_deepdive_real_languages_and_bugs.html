Real Languages, Real Bugs

What JavaScript, Python, C and Haskell actually do, and the places where an associativity or precedence surprise has bitten real programmers.

Measured, not remembered

Actual output of Node v22.14 and Python 3.14 on this machine:

js 2**3**2 = 512
js 10-4-3 = 3
js -2 ** 2 -> SyntaxError Unary operator used immediately before exponentiation expression. Parenthesis must be used to disambiguate operator precedence
a=b=5 -> 5 5
js 100/10/5 = 2
py 2**3**2 = 512
py -2**2 = -4
py 10-4-3 = 3
ExpressionGroups asWhy
10 - 4 - 3(10 - 4) - 3 = 3subtraction is left-assoc (not algebraically associative)
100 / 10 / 5(100 / 10) / 5 = 2division too
2 ** 3 ** 22 ** (3 ** 2) = 512exponent is right-assoc, like the math notation 232

JS -2 ** 2SyntaxErrorJavaScript refuses to guess between (−2)² and −(2²)
Python -2**2-(2**2) = -4Python chose: ** binds tighter than unary minus

The JavaScript/Python difference on -2 ** 2 is a precedence choice, not associativity. JavaScript's designers made the ambiguous form a syntax error instead of picking a winner.

Haskell: the λ-calculus conventions, verbatim

  • Function application is juxtaposition, left-associative, and binds tighter than any operator, exactly like the λ-calculus.
  • The type arrow -> is right-associative: Int -> Int -> Int.
  • $ is declared infixr 0: lowest precedence, right-associative, so f $ g $ h x = f (g (h x)). It exists to escape left-associative application without parentheses.
  • . (composition) is declared infixr 9.

How these become bugs

  • A printer that drops a needed pair of parentheses. Print f (a b) as f a b and a round trip silently changes the program. Module 3's test (5000 random round trips, every paren checked) exists to catch exactly this.
  • A macro that doesn't parenthesize its arguments. The C preprocessor pastes text: #define SQ(x) x*x makes SQ(1+2) into 1+2*1+2 = 5, not 9. That's precedence, and it's the same "text is lossy" lesson as Module 1.
  • Unexpected λ-body extension. f λx. x g is f (λx. x g), not f (λx. x) g. The same thing happens with lambdas in languages where they extend right (for example Haskell's \x -> …).
How this connects

Every one of these is "the tree you meant isn't the tree the text says". The λ-calculus makes it vivid because the whole language is two conventions. Track 2's Alonzo-ML adds infix operators with declared associativity, and its parser tests will reuse Module 3's round-trip idea.
