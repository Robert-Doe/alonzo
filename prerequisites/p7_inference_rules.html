PREREQUISITE P7

Inference-Rule Notation

The fraction bar that fills every programming-languages paper. Once you can read it, papers become readable.

P7.1Above the line: if. Below the line: then.

premise₁    premise₂conclusion

Read it: "if everything above the line holds, then the thing below the line holds." That's all. A rule with nothing above the line is an axiom: it holds unconditionally.

An inference rule is a Lego instruction step.

"Given these two finished pieces (above the line), you may snap them into this bigger piece (below)." Axioms are the raw bricks you can always take from the box. A full derivation is the finished model, built only by following steps.

P7.2Judgments

The statements above and below the line are called judgments. They are claims of a fixed shape. Common ones:

JudgmentRead asFirst used
M → NM steps to NModule 8
Γ ⊢ M : Tin context Γ, term M has type TModule 24
ρ ⊢ M ⇓ vin environment ρ, M evaluates to value vModule 19

Γ (Gamma) is a context: a list of assumptions like x : Int, f : Int → Int. The turnstile ⊢ separates assumptions from the claim.

P7.3Example: the congruence rules for β-reduction

This is a real rule set from Module 8. The β-rule says what a single step does, and the other rules say you may take that step anywhere inside a term:

 (λx. M) N → M[x := N] M → M'M N → M' N N → N'M N → M N' M → M'λx. M → λx. M'

The first is an axiom (β). The other three say "a step inside the function part, the argument part, or a body is a step of the whole."

P7.4Derivations are trees, and checking them is recursion

Stack rules on top of each other and you get a derivation tree, with the final claim at the bottom and axioms at the leaves. A type checker (Module 24) is a recursive function that builds this tree, and its failure message is "no rule's bottom line matches." Tip: to read a rule as code, read it bottom-up. "To show the bottom, go show the tops."

P7.5Where this shows up

  • Module 8: the congruence rules above, as code.
  • Modules 24–31: every type system is a rule set, and every checker walks it.
  • Track H7: Milner's LCF makes "theorems can only come from rules" a guarantee enforced by types.
