PREREQUISITE P5

Structural Induction

How to be sure a claim holds for every λ-term, when there are infinitely many of them.

P5.1From dominoes to trees

Ordinary induction on numbers: prove the claim for 0, and prove "if it holds for n, it holds for n+1." Then it holds for all n. Dominoes: knock the first, and each knocks the next.

Structural induction does the same for trees. Instead of "0" and "n+1," you have one case per node kind:

  • Variable (a leaf): prove the claim directly.
  • Abstraction λx. M: assume it holds for M (the induction hypothesis) and prove it for λx. M.
  • Application M N: assume it holds for M and N, and prove it for M N.
It's the manager-delegation picture from P3, turned into a guarantee.

If every leaf answers correctly, and every manager answers correctly whenever their reports did, then the CEO's answer is correct. No one ever checked the whole company at once.

P5.2A worked example

Claim: in every term, the number of variable occurrences is exactly one more than the number of applications.

  • Variable x: 1 variable, 0 applications. 1 = 0 + 1. ✓
  • Abstraction λx. M: the binder is not an occurrence, so the counts equal M's. By hypothesis, vars(M) = apps(M) + 1. ✓
  • Application M N: vars = vars(M) + vars(N) = (apps(M)+1) + (apps(N)+1) = (apps(M)+apps(N)+1) + 1 = apps(M N) + 1. ✓

Done, for all infinitely many terms. Module 1's test suite checks this exact property on generated terms: code checking the math.

P5.3A proof by structural induction looks like a recursive function

Compare the proof above to size in P3.3. Same three cases, same "use the answer for the children." That resemblance is not an accident. In Module 27 (Curry–Howard) and Module 31 (a mini proof assistant) you'll see that an induction proof literally is a recursive function.

P5.4Where this shows up

  • Module 4: free variables are defined by structural recursion, and their properties hold by structural induction.
  • Module 5: "substitution never captures" is argued case by case.
  • Module 25: why well-typed terms terminate. The proof (Tait's) is a clever strengthened induction.
  • Module 31: you'll write induction proofs that a machine checks.
